The language, its limits, and execution safety +

Small by design

Use fn, let, return, if / else, and while. Every variable, parameter, and function result has type i32 or bool. Locals are mutable. Arithmetic wraps to signed 32 bits; division by zero and signed division overflow trap. Boolean && and || short-circuit.

Explicit boundaries

No strings, arrays, heap, imports, or I/O. Every function must visibly return on all paths. This uses structured IR, not SSA, and does not perform register allocation. The reference interpreter limits call depth to 128 in this demo; browser Wasm recursion limits can differ.

A bounded experiment

Each execution has 100,000 units of fuel: one per function entry and loop-condition check. Optimization can reduce fuel use, so exhaustion is a resource limit, not a claim of semantic disagreement. Work happens in a fresh Worker, terminated after three seconds. Source stays in this page and is not sent to a service.
